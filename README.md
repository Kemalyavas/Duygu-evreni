# Duygu Evreni

3D emotion-sharing platform. Anonymous emotions appear as stars orbiting themed planets. Live at **[duygu-evreni.vercel.app](https://duygu-evreni.vercel.app)**.

## Highlights

- Three.js scene with InstancedMesh rendering 10,000+ simultaneous objects
- Performance-optimized WebGL rendering
- Next.js + TypeScript

## Run locally

```bash
npm install
npm run dev
```
